# Rookery voice samples

Rendered by the Rookery authors with Xfer Serum from original patches; no Serum presets or wavetable files are included. Serum is a build-time authoring tool only; users do not need Serum to run Rookery.

The committed FLAC one-shots are the source of truth for shipped voice audio. The build tool and parameter-only patches live in `tools/voices/`; rendering requires a locally installed compatible Serum VST3 and `pedalboard`.
