## Risks / acceptance
- Chord changes during sustained pad notes can leave old notes overlapping a new chord; test active-note harmony as well as event starts.
- Different role registers must be disjoint. Existing `auto_chord_tone`, combo layers, and D bonuses must respect chord tones/registers.
- Preserve the renderer's legacy no-flock hash/PCM behavior; edits confined to flock code/catalog should do so.
- Listening WAVs must be generated by the actual full project renderer and deterministic.
